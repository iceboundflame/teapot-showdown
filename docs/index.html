Teapot Showdown

A hand–eye challenge for 3D input devices: how quickly can you move and rotate an object onto a target? Every match is one full 6–degree–of–freedom alignment — the bread and butter of CAD, 3D modeling, and scene layout work.

Why it exists

The game doubles as a benchmark for comparing input devices on equal terms: a regular mouse, a 3Dconnexion SpaceMouse, a touchscreen, and the Rotatrix trackball all play the same poses. Each run records how long every single match took, and the stats page compares median motion times per device — so the argument about which device is faster can be settled with your own data.

How to play

  1. Pick a mode: rotation only, translation only, or both.
  2. Line the solid teapot up with the ghost; hold it inside the tolerance briefly to lock the match.
  3. The ghost jumps to a new pose — repeat until the clock runs out. More matches wins; ties break on speed.

Everything is stored locally in your browser — nothing leaves your device.

SpaceMouse

  1. Plug in your SpaceMouse.
  2. Install the 3Dconnexion 3DxWare driver and make sure the 3DxNLServer service is running (it starts with the driver).
  3. Pick SpaceMouse on the start screen and allow the page access to local devices when the browser asks.

Rotatrix

Don’t have one? Get a Rotatrix at rotatrix.com.

  1. Run the Rotatrix app.
  2. Under Integrations, enable Local HTTPS support (required when playing the hosted https version of this game).
  3. Create a new profile named teapot_showdown, click Edit as YAML, and paste the profile below.
drag: rotate · shift/right-drag: pan · wheel: depth · space: peek at target · R: reset teapot · Esc: cancel
